EXPECTED PACKAGE MANIFEST — Delta Electric Services -> TWO CARRIERS SIMULTANEOUSLY

This scenario tests that the system produces genuinely DIFFERENT
packages from the SAME underlying submission data, per PA-01/PA-05 -
not a single generic package sent to two carriers.

STATUS: READY TO SEND

requirement is only 3 years. Cover letter should NOT apologize for or
draw attention to loss history length here, since doing so would be
introducing a non-issue.

--- PACKAGE 2: Meridian Excess & Surplus ---
STATUS: BLOCKED
  [x] ACORD 125, ACORD 126, current financials
  [ ] Loss run: only 3 of 5 required years provided

Draft Cover Letter tone: If broker proceeds despite the gap (their

flagged uniformly across every package - it should be evaluated against

CRITICAL TEST: a naive implementation might generate one cover letter
template and reuse it for both carriers with minor swaps. The correct
behavior is that the loss-run-length concern appears ONLY in the
Meridian package, not the Ironclad one, because it is only a real gap
relative to Meridian's stated requirement.
